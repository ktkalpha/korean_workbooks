# 국어 학습지 제작

## 이 저장소가 하는 일

- **학습지 사이트** (`index.html`): 지문 하나를 A4 한 장(긴 작품은 여러 장)으로 그린다. 교사가 화면에서 빈칸을 만들고 **인쇄**한다.
  컴퓨터 전용·출력용이다. 모바일 대응, 학생이 화면에 직접 쓰는 기능은 만들지 않는다.
  - 빈칸 만들기: ① **빈칸 지정** 켜고 필기·핵심어 클릭 ② 아무 글자나 **드래그**하면 그 범위만 빈칸 ③ **자동 빈칸**(대상·비율 선택)
  - 번호 표시, 정답 보기, 학습지 인쇄 / 정답지 인쇄. 빈칸 상태는 브라우저 localStorage에 지문별 저장
    (`wb:blanks:<id>` 클릭 빈칸, `wb:drags:<id>` 드래그 빈칸 = 학습지 글자 위치). **지문 내용을 고치면 드래그 빈칸 위치가 어긋날 수 있으니** 사용자에게 알린다.
- **PDF 표시하기** (`index.html#/pdf`, `js/annotate.js`): 사용자가 교과서 PDF를 Claude에게 보내기 전에 상자로
  **담기(초록) / 버리기(빨강) / 중요(주황) / 메모(파랑)**를 표시하고 전체 메모를 적어 `<원본>_표시.pdf`로 저장한다.
- **단일 HTML** (`tools/bundle.py` → `out/국어학습지.html`): 사이트 전체(지문·글꼴 일부·PDF 라이브러리)를 파일 하나로 묶는다. 사용자는 이 파일을 받아서 쓴다.

완성 예시 — 새 지문은 가장 비슷한 예시를 먼저 읽고 형식을 맞춘다.
- `data/passages/jemangmaega.js` 제망매가: 고전 시가(옛한글·현대어 풀이·묶음 괄호·낙구 화살표·향가→시조 비교)
- `data/passages/sipnyeoneul.js` 십 년을 경영하여: 평시조(짧은 본문, 오른쪽 필기 근경↓원경, 음보 표)
- `data/passages/namudo.js` 나무도 바윗돌도 없는: 사설시조(긴 줄을 교과서대로 나눠 적기, 여러 줄에 걸친 「 」)
- `data/passages/namsinuiju.js` 남신의주 유동 박시봉 방: 긴 현대시, **두 장**(`pageBreak`, 각주 `line`, 정리 카드 7개)

## 사용자 선호 (지금까지 확인된 것)

- 답은 **한국어**로, 짧게. 결과물은 파일로 **채팅에 보낸다**(SendUserFile): 학습지 PDF 미리보기 + 갱신한 `out/국어학습지.html`.
- 글꼴은 **KoPubWorld 바탕/돋움**(옛한글 지원). 구버전 KoPub(npm `font-kopub`)은 옛한글이 없으니 쓰지 않는다.
- 한 지문 = **A4 한 장**. 단, 긴 작품(예: 32행 「남신의주 유동 박시봉 방」)은 **여러 장 허용**(사용자 확인). 필기는 교과서처럼 **표시한 부분 바로 밑**에.
- 교과서·지도서 내용을 충실히. 교과서에 없는 내용(일반 상식, 직접 나눈 음보 등)을 넣었으면 **끝에 따로 알려** 확인받는다.
  판독이 불확실한 글자(PDF 추출에서 빠진 옛한글 등)도 알린다.

## 절차

0. **표시한 PDF를 받았으면 먼저 읽는다**: `python3 tools/read_marks.py <파일_표시.pdf> <출력 폴더>`
   - 전체 메모와 표시 목록(번호·쪽·종류·메모·상자 안 글자)이 나오고, `page-N.png`(표시된 쪽), `mark-N.png`(상자 부분)가 생긴다. 이미지를 꼭 열어 본다.
   - **담기** = 반드시 학습지에 넣는다. **버리기** = 넣지 않는다(쪽 전체 버리기면 그 쪽은 무시).
     **중요** = 필기·정리에서 강조하고 `{{ }}` 빈칸 후보로 삼는다. **메모** = 적힌 요청을 따른다. 상자에 붙은 메모가 종류보다 우선한다.
   - PDF 끝의 "학습지 제작 표시 목록" 쪽은 사용자가 만든 목록이지 교과서가 아니다(`originalPages` 이후 쪽).
   - 표시가 없는 부분은 아래 기본 원칙대로 판단한다.
1. **자료 읽기**
   - PDF 텍스트: PyMuPDF(`page.get_text()`). poppler의 pdftotext는 한글 CID 글꼴에서 깨진다.
   - 필기 위치·표시 모양(밑줄/동그라미/네모/세모, 「 」 범위, ▶ 단계 요약)은 페이지를 이미지로 렌더링해서 **눈으로** 확인한다(필요하면 `get_pixmap(clip=…, dpi=200)`으로 확대).
   - PDF 추출에서 옛한글 글자는 자주 빠진다. 빠진 자리는 이미지·사용자가 준 사진으로 복원한다.
   - 교과서의 학습 활동·날개(작가 소개, 제재 개관, 갈래 설명, 활동 예시 답)도 정리 카드의 재료다.
2. **id 정하기**: 작품명 로마자 소문자(예: `jemangmaega`, `sipnyeoneul`, `namudo`). `order`는 교과서 순서.
3. **데이터 파일 작성**: `data/passages/<id>.js` — 아래 형식.
4. **목록 등록**: `data/manifest.js`의 배열에 id 추가.
5. **검사**: `NODE_PATH=$(npm root -g) node tools/check.mjs <id> <출력 폴더>`
   - 종료 코드 0이어야 한다. `overflowPx` 0, `pdfPages` = `sheets`(장 수), `noteOverlapLines`·`wideLines`(칸을 넘는 본문 줄)·`errors` 빈 배열.
   - `scale`은 넘칠 때 자동 축소된 비율. **0.85 미만이면** 카드를 줄이거나 문장을 다듬는다(아래 정리 카드 규칙).
   - 만들어진 PNG를 반드시 열어 본다: 필기가 표시 바로 밑인지, 괄호·화살표가 맞는 줄인지, 카드 그리드에 빈 칸이 없는지.
   - 사이트 코드(`js/`, `css/`)를 고쳤으면 **모든 지문**을 다시 검사한다.
6. **묶기**: `python3 tools/bundle.py` → `out/국어학습지.html` (out/은 git에 안 올라감).
   브라우저로 열어 목록·학습지가 뜨는지 확인한다.
7. 커밋·푸시하고, 학습지 PDF(검사 도구가 만든 것)와 `out/국어학습지.html`을 채팅으로 보낸다.

## 데이터 형식

```js
WB.register({
  id: 'jemangmaega', order: 1,
  unit: '1. 한국 문학의 흐름', lesson: '(1) 제망매가 / 시조 두 수',
  title: '제망매가', hanja: '祭亡妹歌', author: '월명사',
  source: '김완진 해독, 『향가 해독법 연구』', genre: '10구체 향가',
  passage: {
    textLabel: '원문 (김완진 해독)', stageLabel: '시상 전개', transLabel: '현대어 풀이',
    gutter: '24mm',      // 왼쪽 여백(묶음 괄호 설명 자리). 괄호가 없으면 '0mm'~'6mm'
    stageWidth: '37mm',  // 시상 전개 칸 너비 (현대어 풀이 없으면 기본 42mm)
    textSize: 1.42,      // 본문 글자 크기(em). 짧은 시조 1.6, 긴 줄(사설시조·산문) 1.2~1.3
    lines: [ { text, trans?, side?, under?, underAt?, gapBefore?, stage?: { tag, text } }, ... ],
    brackets: [ { from, to, label } ],       // 줄 번호 1부터. 왼쪽 여백의 묶음 괄호 + 설명
    rightNotes: [ { from, to, text } ],      // 해당 줄들 오른쪽 끝에 세로로 붙는 필기 (예: '근경\n↓\n원경')
    closing: { from, text, sub? },           // from 줄부터 아래로 화살표 → 지문 밑 설명(시상 전환 등)
    footnotes: [ { n, term, text, line? } ], // 교과서 번호 그대로. 2단. 번호가 나오는 장에 붙음(장마다 번호가 1부터면 line=줄 번호로 지정)
  },
  summary: [ 카드, ... ],
});
```

### 본문 줄 `text` 마크업 — 교과서 필기 형식

필기는 **표시한 부분 바로 밑**, 가운데에 자동 배치된다(겹치면 옆으로 밀림).

| 문법 | 뜻 |
|---|---|
| `[대상]{u:필기}` | 밑줄 + 밑에 필기 |
| `[대상]{c:필기}` | 동그라미 (한두 글자) |
| `[대상]{b:필기}` | 네모 |
| `[대상]{t:필기}` | 세모 (감탄사 등) |
| `[대상]{w:필기}` / `{d:필기}` | 물결 밑줄 / 겹밑줄 |
| `[대상]{n:필기}` | 표시 없이 필기만 |
| `[대상]{b}` | 표시만, 필기 없음 |
| `[대상]{b<:필기}` | 필기를 대상 **왼쪽 끝**에 맞춤 (긴 필기, 기호 범례 `□: …`) |
| `^1` | 각주 번호(주황 위첨자). `[ ]` 안에서도 됨 |
| 필기 안 `\n` | 필기 줄바꿈 |
| 필기 안 `{{핵심어}}` | 그 부분만 빈칸 후보 |

- `side`: 줄 끝에 붙는 작은 필기(예: `→ ᄇᆞᄅᆞᆷ+애` 같은 형태 분석).
- `under`: 단어가 아닌 **범위 전체**에 대한 필기를 그 줄 밑 왼쪽에 단다(예: `「 」: …(의인법) → 물아일체`). `underAt`은 들여쓰기(본문 em).
- 범위 표시 「 」는 본문에 글자 그대로 넣는다. 여러 줄에 걸치면 시작 줄에 「, 끝 줄에 」, `under`는 범위 가운데 줄에.
- `gapBefore: true`: 장·연이 바뀌는 줄 위에 여백.
- `pageBreak: true`: 그 줄부터 **다음 장**(여러 장 학습지). 정리 카드는 마지막 장에 들어가고, 모든 장이 같은 비율로 축소된다.
  각 장의 빈 공간이 비슷하도록 나눌 위치를 정한다(검사 결과 `spareMm`이 장별로 나온다). 둘째 장부터 PNG는 `<id>-2.png`, `<id>-3.png`.
- 긴 줄(사설시조, 산문시)은 **교과서의 줄바꿈 그대로** 여러 줄로 나눠 적는다(한 줄 = 한 `lines` 항목). 사이트는 본문을 자동 줄바꿈하지 않는다. `wideLines`가 나오면 `textSize`를 줄이거나 줄을 다시 나눈다.
- `stage`: 오른쪽 "시상 전개" 칸(태그 + 내용). 단락·연·장이 끝나는 줄에 단다. 태그는 `기/서/결`, `초장/중장/종장`, `1연` 등 짧게.
- `trans`: 현대어 풀이(고전 작품). 하나라도 있으면 현대어 풀이 칸이 생긴다. 현대 작품은 생략.
- 한 줄에 필기가 많아 겹치면 짧게 줄이거나 `\n`으로 나눈다.

### 빈칸 단위 (클릭·자동 빈칸 대상)

- 필기·정리 문장에 `{{핵심어}}`가 있으면 **그 부분만**, 없으면 **문장 전체**가 하나의 빈칸 후보다.
- 표시한 본문 대상(`[ ]` 안)과 현대어 풀이 각 줄도 빈칸 후보다. 그 밖의 글자는 사용자가 드래그로 뚫는다.
- 정리 카드에는 시험에 나올 용어(갈래, 성격, 주제어, 표현법 이름, 시어의 의미)를 `{{ }}`로 감싼다. 조사·서술어는 밖에: `'{{애상적}}, {{추모적}}'`.
- `**굵게**`는 강조만, 빈칸 아님.

### 정리 카드 (`summary`) — 3열 그리드

| type | 필드 | 쓰임 |
|---|---|---|
| `table` | `rows: [[항목, 내용]]` | 작품 개관(갈래·성격·주제·작가·출전·특징·의의) |
| `stages` | `rows: [[범위, 태그, 내용]]` | 시상 전개(기·서·결, 초·중·종장, 연별) |
| `map` | `rows: [[시어, 의미]]` | 시어·소재의 의미 |
| `flow` | `steps: [..]` | 화자의 태도·정서 변화(▼로 연결) |
| `list` | `items: [..]` | 갈래 이해, 감상 포인트, 표현상 특징 |
| `text` | `text` | 짧은 설명 |
| `compare` | `head: ['', 'A', 'B']`, `rows: [[항목, a, b]]` | 두 작품·갈래 비교 (향가↔시조, 평시조↔사설시조, 비교 대상) |
| `meter` | `rows: [['초장', 음보1, 음보2, 음보3, 음보4]]` | 시조 음보 나누기 |

모든 카드에 `foot: '…'`를 주면 아래에 결론 띠가 붙는다. `span: 2|3`(가로), `rowSpan: 2`(세로).

- **한 행의 칸 수 합이 3**이 되게 순서를 짠다(예: [개관 2 + 시상 전개 1], [음보 2 + 표현 1], [비교 3]). 빈 칸이 생기면 보기 흉하다.
  긴 표 카드는 `span: 2, rowSpan: 2`로 두고 옆 열에 짧은 카드 두 개를 쌓는다.
- 남는 세로 공간은 카드가 늘어나 채운다. 넘쳐서 `scale`이 0.85 미만이면 **필기와 겹치는 카드**(필기에 이미 있는 시어 풀이 등)부터 빼고, 중복 문장을 줄인다.
- 갈래가 문학사적으로 이어지면(10구체 향가→시조의 3장 구성·종장 감탄사, 평시조→사설시조) 그 연관성을 `compare` 카드로 넣는다. 사용자가 특히 원한 내용이다.
- 기본 구성: 작품 개관 → 시상 전개 → 화자의 태도/정서 → 시어의 의미 → 표현상 특징 → 갈래 이해·비교. 교과서·지도서의 정리 항목이 있으면 그것을 따른다.
- 교과서 설명과 어긋나는 자기 해석(예: "사설시조 초장은 평시조와 길이가 같다")을 넣지 않는다.

## 옛한글

옛한글은 반드시 **조합형 자모(U+1100–11FF, A960–A97F, D7B0–D7FF)**로 쓴다. 호환 자모(ㆍ U+318D 등)로 쓰지 않는다.
현대 음절은 완성형(가–힣) 그대로, 옛 글자가 들어간 음절만 자모로 쓴다.

| 글자 | 자모 |
|---|---|
| 아래아 ᆞ | U+119E (예: ᄂᆞᆫ = 1102 119E 11AB) |
| 반치음 ᅀ | U+1140 (ᄀᆞᅀᆞᆯ = 1100 119E 1140 119E 11AF) |
| ᄠ | U+1120 (ᄠᅥ = 1120 1165) |
| ㆁ 옛이응 | U+114C, 받침 U+11F0 |
| ᅙ 여린히읗 | U+1159 |
| ᄫ 순경음 비읍 | U+112B |

작성 뒤 코드포인트 확인:
`python3 -c "import re,sys;s=open(sys.argv[1]).read();[print(m,[hex(ord(c)) for c in m]) for m in sorted(set(re.findall('[ᄀ-ᇿꥠ-꥿ힰ-퟿]+',s)))]" data/passages/<id>.js`

## 디자인 규칙 (일관성 유지)

- 본문 KoPubWorld 바탕, 필기·정리·UI KoPubWorld 돋움. 필기색 `#1d6083`(교과서 청록), 각주 번호 `#c0682a`.
- 머리(갈래 칩 · 제목 · 작가/출전 · 학번/이름) → Ⅰ 지문 읽기·필기 → Ⅱ 갈래 및 특성 정리 → 바닥글.
- 새 표시 기호·카드 형식이 꼭 필요할 때만 `js/app.js`·`css/sheet.css`를 고치고, 이 문서의 표에 추가한다.

## 도구

| 명령 | 하는 일 |
|---|---|
| `NODE_PATH=$(npm root -g) node tools/check.mjs <id> <폴더>` | 한 장 맞춤·필기 겹침·줄 넘침·글꼴 검사, PNG·PDF 생성 |
| `python3 tools/bundle.py [출력]` | 단일 HTML 생성(글꼴은 쓰인 글자만 내장, pdf.js·pdf-lib 포함) |
| `python3 tools/read_marks.py <_표시.pdf> [폴더]` | 사용자가 표시한 PDF 읽기(내장 JSON `workbook-marks.json` → 없으면 주석 `학습지 표시`) |

라이브러리는 `vendor/`(pdf.js 3.11.174, pdf-lib 1.17.1, 한국어 CMap)에 있다. PDF 표시하기는 file://에서도 돌도록 pdf.js 워커를 일반 스크립트로 불러 같은 스레드에서 처리한다.

## 하지 말 것

- 한 장에 들어가는 지문을 여러 장으로 늘리지 않는다. 여러 장은 긴 작품에만.
- 모바일 대응·화면 필기 기능을 만들지 않는다(컴퓨터에서 인쇄용).
- 표시한 PDF의 **버리기** 부분을 학습지에 넣지 않는다.
