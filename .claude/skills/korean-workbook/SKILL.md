# 국어 학습지 제작

이 저장소는 정적 사이트다(`index.html`). 지문 하나 = 데이터 파일 하나(`data/passages/<id>.js`).
사이트가 데이터를 A4 한 장으로 그리고, 교사는 화면에서 빈칸을 지정한 뒤 **인쇄**한다(컴퓨터 전용, 출력용).
완성 예시 — 새 지문은 가장 비슷한 예시를 먼저 읽고 형식을 맞춘다.
- `data/passages/jemangmaega.js` 제망매가: 고전 시가(옛한글·현대어 풀이·묶음 괄호·낙구 화살표)
- `data/passages/sipnyeoneul.js` 십 년을 경영하여: 평시조(짧은 본문, 오른쪽 필기 근경↓원경, 음보 표)
- `data/passages/namudo.js` 나무도 바윗돌도 없는: 사설시조(긴 줄을 교과서대로 나눠 적기, 여러 줄에 걸친 「 」)

## 절차

1. **자료 읽기**
   - PDF 텍스트: `python3 -c "import pymupdf; ..."`로 `page.get_text()` (poppler의 pdftotext는 한글 CID 글꼴에서 깨진다).
   - 필기 위치·표시 모양(밑줄/동그라미/네모/세모, 괄호 범위, ▶ 단계 요약)은 페이지를 이미지로 렌더링해서 **눈으로** 확인한다.
   - PDF 추출에서 옛한글 글자는 자주 빠진다. 빠진 자리는 이미지·사용자가 준 사진으로 복원한다.
2. **id 정하기**: 작품명 로마자 소문자(예: `jemangmaega`, `sipnyeoneul`). `order`는 교과서 순서.
3. **데이터 파일 작성**: `data/passages/<id>.js` — 아래 형식.
4. **목록 등록**: `data/manifest.js`의 배열에 id 추가.
5. **검사**: `NODE_PATH=$(npm root -g) node tools/check.mjs <id> <출력 폴더>`
   - 종료 코드 0이어야 한다. `overflowPx` 0, `pdfPages` 1, `noteOverlapLines`·`wideLines`(칸을 넘는 본문 줄)·`errors` 빈 배열.
   - `scale`은 내용이 넘칠 때 자동 축소된 비율. **0.85 미만이면** 정리 카드를 줄이거나 문장을 다듬는다.
   - 만들어진 PNG를 반드시 열어 보고 필기가 표시 바로 밑에 놓였는지, 괄호·화살표가 맞는 줄에 걸렸는지 확인한다.
6. 커밋·푸시.

## 데이터 형식

```js
WB.register({
  id: 'jemangmaega', order: 1,
  unit: '1. 한국 문학의 흐름', lesson: '(1) 제망매가 / 시조 두 수',
  title: '제망매가', hanja: '祭亡妹歌', author: '월명사',
  source: '김완진 해독, 『향가 해독법 연구』', genre: '10구체 향가',
  passage: {
    textLabel: '원문 (김완진 해독)', stageLabel: '시상 전개', transLabel: '현대어 풀이',
    gutter: '24mm',      // 왼쪽 여백(묶음 괄호 설명 자리). 괄호가 없으면 '0mm'~'6mm'
    stageWidth: '37mm',  // 시상 전개 칸 너비 (현대어 풀이 없으면 기본 42mm)
    textSize: 1.42,      // 본문 글자 크기(em). 긴 줄(사설시조·산문)은 1.2~1.3
    lines: [ { text, trans?, side?, under?, underAt?, gapBefore?, stage?: { tag, text } }, ... ],
    brackets: [ { from, to, label } ],       // 줄 번호 1부터. 왼쪽 여백의 묶음 괄호 + 설명
    rightNotes: [ { from, to, text } ],      // 해당 줄들 오른쪽 끝에 세로로 붙는 필기 (예: '근경\n↓\n원경')
    closing: { from, text, sub? },           // from 줄부터 아래로 화살표 → 지문 밑 설명(시상 전환 등)
    footnotes: [ { n, term, text } ],        // 2단으로 배치됨
  },
  summary: [ 카드, ... ],
});
```

### 본문 줄 `text` 마크업 — 교과서 필기 형식

필기는 **표시한 부분 바로 밑**, 가운데에 자동 배치된다(겹치면 옆으로 밀림).

| 문법 | 뜻 |
|---|---|
| `[대상]{u:필기}` | 밑줄 + 밑에 필기 |
| `[대상]{c:필기}` | 동그라미 (한두 글자) |
| `[대상]{b:필기}` | 네모 |
| `[대상]{t:필기}` | 세모 (감탄사 등) |
| `[대상]{w:필기}` / `{d:필기}` | 물결 밑줄 / 겹밑줄 |
| `[대상]{n:필기}` | 표시 없이 필기만 |
| `[대상]{b}` | 표시만, 필기 없음 |
| `[대상]{b<:필기}` | 필기를 가운데가 아니라 대상 **왼쪽 끝**에 맞춤 (긴 필기, 기호 범례 `□: …`) |
| `^1` | 각주 번호(주황 위첨자) |
| 필기 안 `\n` | 필기 줄바꿈 |

- `side`: 줄 끝에 붙는 작은 필기(예: `→ ᄇᆞᄅᆞᆷ+애` 같은 형태 분석).
- `under`: 특정 단어가 아닌 **범위 전체**에 대한 필기를 그 줄 밑 왼쪽에 단다(예: `「 」: …(의인법) → 물아일체`). `underAt`은 들여쓰기(본문 em).
- 범위 표시 「 」는 본문에 글자 그대로 넣는다. 여러 줄에 걸치면 시작 줄에 「, 끝 줄에 」를 넣고 `under`는 범위 가운데 줄에 단다.
- `gapBefore: true`: 장·연이 바뀌는 줄 위에 여백.
- 긴 줄(사설시조, 산문시)은 **교과서의 줄바꿈 그대로** 여러 줄로 나눠 적는다(한 줄 = 한 `lines` 항목). 사이트는 본문을 자동 줄바꿈하지 않는다. `wideLines`가 나오면 `textSize`를 줄이거나 줄을 다시 나눈다.
- `stage`: 오른쪽 "시상 전개" 칸의 `▶ 기: …`. 단락·연·장이 끝나는 줄에 단다.
- `trans`: 현대어 풀이(고전 작품). 현대 작품이면 생략하고 `transLabel`을 빈 문자열로.
- 한 줄에 필기가 많아 겹치면 짧게 줄이거나 `\n`으로 나눈다.

### 빈칸 단위

- 필기·정리 문장에 `{{핵심어}}`가 있으면 **그 부분만** 빈칸 후보가 되고, 없으면 **문장 전체**가 하나의 빈칸 후보다.
- 표시한 본문 대상(`[ ]` 안)과 현대어 풀이 각 줄도 빈칸 후보다.
- 정리 카드에는 시험에 나올 용어(갈래, 성격, 주제어, 표현법 이름, 시어의 의미)를 `{{ }}`로 감싼다. 조사·서술어는 밖에 둔다: `'{{애상적}}, {{추모적}}'`.
- `**굵게**`는 강조만, 빈칸 아님.

### 정리 카드 (`summary`) — 3열 그리드

| type | 필드 | 쓰임 |
|---|---|---|
| `table` | `rows: [[항목, 내용]]` | 작품 개관(갈래·성격·주제·작가·출전·특징) |
| `stages` | `rows: [[범위, 단계, 내용]]` | 시상 전개(기·서·결, 초·중·종장, 연별) |
| `map` | `rows: [[시어, 의미]]` | 시어·소재의 의미 |
| `flow` | `steps: [..]` | 화자의 태도·정서 변화(▼로 연결) |
| `list` | `items: [..]` | 갈래 이해, 감상 포인트, 표현상 특징 |
| `text` | `text` | 짧은 설명 |
| `compare` | `head: ['', 'A', 'B']`, `rows: [[항목, a, b]]` | 두 작품·갈래 비교 (향가↔시조, 평시조↔사설시조, 비교 대상) |
| `meter` | `rows: [['초장', 음보1, 음보2, 음보3, 음보4]]` | 시조 음보 나누기 |

모든 카드에 `foot: '…'`를 주면 아래에 결론 띠(→ …)가 붙는다.

- `span: 2`(가로 2칸), `rowSpan: 2`(세로 2칸). 긴 표 카드는 `span: 2, rowSpan: 2`로 두고 옆 열에 짧은 카드 두 개를 쌓으면 빈 공간이 생기지 않는다.
- 3열 그리드이므로 **한 행의 칸 수 합이 3**이 되게 순서를 짠다(예: [개관 2 + 시상 전개 1], [음보 2 + 표현 1], [비교 3]). 빈 칸이 생기면 보기 흉하다.
- 남는 세로 공간은 카드가 늘어나 채운다. 넘치면 글자가 자동 축소되는데 `scale` 0.85 미만이면 **필기와 겹치는 카드**(예: 필기에 이미 있는 시어 풀이)부터 뺀다.
- 갈래가 문학사적으로 이어지는 경우(향가→시조, 평시조→사설시조) 그 연관성을 `compare` 카드로 꼭 넣는다.
- 기본 구성: 작품 개관 → 시상 전개 → (짧은 카드) → 시어의 의미 → 화자의 태도/정서 → 갈래 이해. 교과서·지도서에 있는 정리 항목(표현상 특징, 비교 대상 등)이 있으면 그것을 따른다.
- 내용은 교과서·지도서 표현을 그대로 살린다. 지어내지 않는다. 교과서 설명과 어긋나는 자기 해석(예: "초장은 평시조와 길이가 같다")을 넣지 않는다.

## 옛한글

글꼴은 **KoPubWorld 바탕/돋움**(`fonts/`)이며 첫가끝 조합을 지원한다. 옛한글은 반드시 **조합형 자모(U+1100–11FF, A960–A97F, D7B0–D7FF)**로 쓴다. 호환 자모(ㆍ U+318D 등)로 쓰지 않는다.

| 글자 | 자모 |
|---|---|
| 아래아 ᆞ | U+119E (예: ᄂᆞᆫ = 1102 119E 11AB) |
| 반치음 ᅀ | U+1140 (ᄀᆞᅀᆞᆯ = 1100 119E 1140 119E 11AF) |
| ᄠ | U+1120 (ᄠᅥ = 1120 1165) |
| ㆁ 옛이응 | U+114C, 받침 U+11F0 |
| ᅙ 여린히읗 | U+1159 |
| ᄫ 순경음 비읍 | U+112B |

작성 뒤 확인: `python3 -c "import re;s=open('data/passages/<id>.js').read();[print(m,[hex(ord(c)) for c in m]) for m in sorted(set(re.findall(r'[ᄀ-ᇿꥠ-꥿ힰ-퟿]+',s)))]"`
현대 음절과 섞일 때 완성형 음절(가–힣)은 그대로 쓰고, 옛 글자가 들어간 음절만 자모로 쓴다.

## 하지 말 것

- 학습지를 두 장으로 늘리지 않는다(한 지문 = A4 한 장).
- 사이트 코드(`js/`, `css/`)는 새 표시 기호·카드 형식이 꼭 필요할 때만 고친다. 고쳤다면 기존 지문도 `tools/check.mjs`로 다시 검사한다.
- 모바일 대응은 하지 않는다(컴퓨터에서 인쇄용).
